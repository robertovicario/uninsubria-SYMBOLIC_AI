# Introduction

Artificial Intelligence (AI) studies how to build systems that perform tasks requiring intelligence. This course focuses on ***SYMBOLIC AI***: explicit knowledge representations and reasoning.

## Agents

An agent perceives an environment through ***SENSORS*** and acts through ***ACTUATORS***. The environment can be physical or virtual.

A ***PERCEPT*** $p\in P$ is an observation. A percept sequence $[p_0,\ldots,p_t]\in P^*$ is the observation history.

An ***AGENT FUNCTION*** maps percept histories to actions:

$$
\boxed{f:P^*\to A}
$$

An ***AGENT PROGRAM*** implements this function on a computing architecture. The mathematical function is not necessarily implementable.

A ***PERFORMANCE MEASURE*** evaluates sequences of environment states, rather than percepts alone.

A ***RATIONAL AGENT*** chooses actions expected to maximize performance, given its observations and built-in knowledge. Rationality does not imply omniscience or guarantee success: exploration and learning may improve future decisions.

Limited resources require ***LIMITED RATIONALITY***. Objectives must be specified carefully: optimizing the wrong measure can produce unwanted behaviour.

\bigskip
> ***PEAS***

Before designing, implementing and evaluating agents we need to specify four things ( recognized by the acronym PEAS):

- **(P)erformance Measure:** What is the agent trying to do?
- **(E)nvironment:** What is it like?
- **(A)ctuators:** What can the agent do?
- **(S)ensors:** What can the agent "see"?

\bigskip
> ***Properties of Environments***

| **Property** | **Meaning** |
| - | - |
| Fully / partially / unobservable | all / some / no relevant state information is perceived |
| Single / multi-agent | one agent / multiple cooperating or competing agents |
| Deterministic / nondeterministic | state and actions fix the next state / allow multiple outcomes |
| Episodic / sequential | independent decisions / actions affect future decisions |
| Static / dynamic | unchanged / may change during deliberation |
| Discrete / continuous | distinct countable values / continuous values |
| Known / unknown | rules are known / must be learned through experience |

\bigskip
> ***Architectures***

Architectures can be classified by the type of agent program they support:

- **Simple reflex:** choose from the current percept using condition-action rules. Efficient, but cannot remember past observations.
- **Model-based:** maintain an internal state, updated through percepts and a model of action effects and world changes.
- **Goal-based:** predict action outcomes and choose actions that reach a goal, using search or planning.
- **Utility-based:** compare outcome desirability and maximize expected utility, handling trade-offs and uncertainty.
